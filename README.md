# Лабораторная работа №1: Основы Python

Данный репозиторий содержит решение 11 базовых алгоритмических задач, демонстрацию трехкомпонентной архитектуры проекта (`rare`, `medium`, `well-done`), а также полный отчет по проделанной работе.

---

## 1. Задание

**Цель работы:** Приобретение практических навыков работы с базовыми типами данных и структурами языка Python (числа, строки, списки, словари, множества, кортежи), изучение принципов модульной организации программного обеспечения (`if __name__ == '__main__':`), настройки изолированных виртуальных окружений (`venv`) и написания автоматизированных модульных тестов с использованием фреймворка `pytest`.

### Задачи по уровням сложности:
1. **Rare:** Реализовать 11 базовых скриптов (`00_distance.py` — `10_store.py`). Инкапсулировать исполняемый код каждой задачи в функцию `run()`, защитив ее вызов конструкцией `if __name__ == '__main__':`.
2. **Medium:** Создать управляющий верхнеуровневый модуль `main.py` в папке `medium/`, обеспечивающий последовательный запуск всех 11 задач из директории `rare/`.
3. **Well-done:** Написать тестовый модуль `test_main.py` в папке `well-done/` для автоматической валидации вывода консоли с помощью `pytest`, зафиксировать зависимости в `requirements.txt`.

---

## 2. Структура и организация проекта

Проект структурирован по трехкомпонентной схеме:
* **`rare/`** — папка с базовыми модулями-задачами (`00_distance.py` — `10_store.py`). Код каждой задачи обернут в функцию `run()` для предотвращения автоматического исполнения при импорте.
* **`medium/`** — папка с главным модулем `main.py`, организующим точку входа в приложение и динамический импорт модулей.
* **`well-done/`** — папка с тестами `test_main.py` для автоматической проверки вывода функций.
* **`requirements.txt`** — файл с зафиксированными версиями сторонних библиотек (`pytest` и его зависимости).
* **`.gitignore`** — файл исключения служебных каталогов (`.venv/`, `__pycache__/`).

## 3. Выполнение заданий (Уровень Rare)

* **`00_distance.py` — Расстояния между городами:** Расчет евклидовых расстояний между координатами городов на плоскости по формуле $d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$. Результат записан в виде вложенного словаря `distances`.
* **`01_circle.py` — Площадь круга и проверка точек:** Вычислена площадь круга $S = \pi \cdot r^2$ с округлением до 4 знаков после запятой с помощью `round()`. Осуществлена проверка попадания двух заданных точек в круг через сравнение расстояния до начала координат с радиусом.
* **`02_operations.py` — Арифметическое выражение:** Расставлены математические знаки и скобки между последовательностью чисел `1 2 3 4 5` для получения итогового значения `25` (`1 * (2 + 3 + 4 * 5)`).
* **`03_favorite_movies.py` — Работа со срезами:** Из исходной строки с фильмами с помощью срезов (slice) извлечены названия первого, последнего, второго и второго с конца фильмов без применения методов `.split()` и `.find()`.
* **`04_my_family.py` — Списки членов семьи:** Создан вложенный список с именами и ростом членов семьи. Выполнен доступ к элементам по индексам для вывода роста отца и подсчета суммарного роста семьи с помощью цикла `for`.
* **`05_zoo.py` — Изменение списка животных:** Выполнены операции модификации списка `zoo`: вставка элемента по индексу (`insert`), расширение списка другим списком (`extend`), удаление элемента (`remove`) и поиск 1-индексированных номеров клеток (`index() + 1`).
* **`06_songs_list.py` — Суммарная длительность песен:** Осуществлен выбор элементов и суммирование времени звучания треков из списка списков и из словаря. Результаты округлены до 3 знаков после запятой (`round()`).
* **`07_secret.py` — Расшифровка строки:** Зашифрованный текст извлечен из элементов списка с применением прямых, шаг-срезов и обратных срезов (`[start:stop:step]`). Из полученных слов сформирована итоговая фраза.
* **`08_garden.py` — Операции над множествами:** Кортежи цветов преобразованы в множества (`set`). Выполнены теоретико-множественные операции: объединение (`|`), пересечение (`&`) и разность множеств (`-`).
* **`09_shopping.py` — Выбор двух минимальных цен:** На основе данных о ценах в магазинах вручную сформирована структура данных `sweets`, содержащая по два магазина с наименьшими ценами для каждого вида товаров.
* **`10_store.py` — Складские партии:** Реализован двойной цикл для связи кодов товаров из словаря `goods` со списком партий из словаря `store`. Вычислено общее количество и суммарная стоимость каждого товара на складе.

## 4. Требования и инструкция по запуску

Для корректного запуска проектов и автотестов рекомендуется использовать изолированное виртуальное окружение.

### 1. Настройка виртуального окружения
Создайте и активируйте виртуальное окружение в корневой папке проекта:

```bash
# Создание venv
python -m venv .venv

# Активация venv (Linux / macOS):
source .venv/bin/activate

# Активация venv (Windows PowerShell):
.venv\Scripts\Activate.ps1
```

Установите требуемые зависимости из `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 2. Запуск точечных скриптов (Rare)

Любую из задач можно запустить изолированно напрямую из папки `rare`:

```bash
python rare/00_distance.py
```

### 3. Верхнеуровневый запуск (Medium)

Для запуска всех 11 задач одной командой через модуль `main.py`:

```bash
python medium/main.py
```

### 4. Запуск автоматизированных тестов (Well-done)

Для запуска тестов на базе `pytest` убедитесь, что виртуальное окружение активировано, и выполните:

```bash
pytest well-done/test_main.py -v
```

## 5. Памятка по работе с Git

Во время работы над проектом применялись следующие основные команды VCS Git:

* `git status` — проверка состояния рабочего дерева и индекса.
* `git add .` — добавление измененных файлов в индекс для коммита.
* `git commit -m "описание"` — фиксация изменений из индекса в истории репозитория.
* `git push` — отправка локальных коммитов в удаленный репозиторий на GitHub/GitLab.
* `git pull` — получение актуальных изменений из удаленного репозитория.
* `git log --oneline` — краткий просмотр истории коммитов.
